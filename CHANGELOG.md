# 0.0.2

- Добавлена кнопка в профиле пользователя для отображения всех трофеев пользователя
- Добавлено отображение примерного числа просмотров, продаж, отзывов, жалоб в профиле пользователя
- Добавлено отображение вычисленных "меток" в профиле пользователя
- Добавлена поддержка отправки медиа вместе с сообщением
- Добавлена возможность задать домен маркета с помощью переменной окружения `MARKET_BASE` (по умолчанию `https://lzt.market`)
- Стандартный API домен изменен на `api.lolz.live` (раньше был `prod-api.lolz.live`)
